# 搬瓦工购买教程：从选套餐到支付宝付款的完整流程，新手也能一次买对

很多人第一次接触搬瓦工（BandwagonHost）时，并不是被它的功能劝退，而是被套餐列表劝退——KVM、CN2 GIA-E、香港 CN2 GIA、东京 CN2 GIA、新加坡 CN2 GIA、Dubai ECOMMERCE，再加上一堆机房缩写，光看名字就够绕的。这篇搬瓦工购买教程会把这些东西拆开讲清楚：每条线路实际意味着什么、不同套餐差在哪里、注册和付款具体怎么走、优惠码怎么填、买完之后怎么用。

## 一、先搞清楚搬瓦工到底卖的是什么

搬瓦工卖的是 KVM 架构的 VPS（虚拟专用服务器），自助管理。简单说，你租的是一台远程 Linux 机器，有完整的 root 权限，可以自己装系统、跑程序、建站、搭代理、做测试环境，随便折腾。

所有 VPS 都基于自研的 KiwiVM 控制面板，能做的操作包括：开机/关机/重启、重装系统、紧急控制台（VNC）、rDNS（PTR 反向解析）设置、机房迁移、快照、流量统计、API 调用等。系统模板覆盖 AlmaLinux、RockyLinux、CentOS、Debian、Ubuntu、CentOS Stream、Fedora，32 位和 64 位都有。

需要先说明的是：搬瓦工是**自助管理型**服务。官方提供面板、网络、硬件保障和 99.9% 在线率承诺，但不会帮你装环境、配 Nginx、调数据库。你能自己折腾 Linux 命令行，或者愿意边查边学，再考虑下单。

## 二、套餐怎么选：先把线路和机房分清楚

搬瓦工的套餐按"线路 + 规格"两个维度划分。规格就是 CPU、内存、SSD、流量这些，比较好理解；真正容易绕晕的是线路。下面按从便宜到贵、从普通到高端的顺序讲。

### 1. KVM 普通线路套餐

这是最便宜的一档，走的是普通国际线路，机房主要在美国（洛杉矶 DC2 QNET、DC4 MCOM、DC8 ZNET、Fremont、新泽西 USNJ、纽约 USNY_2/USNY_6）、加拿大（CABC_1）和荷兰（EUNL_3）。

适合场景：预算有限、对延迟不敏感、做开发测试、跑爬虫、放点不重要的服务。从国内访问延迟较高，晚高峰可能会绕路。

### 2. CN2 GIA-E（电商优化线路）

这是搬瓦工目前主推的性价比方案，走中国电信 CN2 GIA-E 优化线路，国内访问延迟低、晚高峰相对稳定。可选机房包括 DC6 CN2 GIA-E、DC9 CN2 GIA、日本软银 JPOS_1、荷兰 EUNL_9，以及香港、东京、新加坡的 CN2 GIA 节点，并且支持在这些机房之间互相迁移。

带宽从 2.5Gbps 起步，高端套餐到 10Gbps。适合场景：长期建站、跑业务、对国内访问速度有要求、希望机房能灵活切换。

### 3. 香港 / 东京 / 新加坡 CN2 GIA 专属线路

这三个是机房位置固定的 CN2 GIA 方案，不能像 CN2 GIA-E 那样在多个机房之间迁移，但线路质量更高，延迟更低。

- **香港 CN2 GIA**：1Gbps 带宽，国内访问延迟最低，但价格最贵，2GB 起步套餐 $89.99/月。
- **东京 CN2 GIA**：1.2Gbps 带宽，日本节点，延迟和稳定性都不错，价格和香港持平。
- **新加坡 CN2 GIA**：1.5Gbps 带宽，东南亚方向访问友好，价格相对东京和香港略低。

适合场景：对延迟有硬性要求、预算充足、不需要频繁切换机房。

### 4. Dubai ECOMMERCE 套餐

迪拜机房，走阿联酋 AEDXB_1 节点，同时支持迁入 DC6 CN2 GIA-E、DC9 CN2 GIA、JPOS_1、EUNL_9 等 CN2 GIA-E 机房。1Gbps 带宽，1GB 起步套餐 $19.99/月，是进入 CN2 GIA-E 体系的最低门槛之一。

适合场景：想用 CN2 GIA-E 线路但预算有限，先从迪拜机房入手，之后迁到 DC6 或 DC9。

### 怎么选

如果只是个人玩、学习、跑点轻量任务，KVM 普通线路 $49.99/年起步够用。如果要做长期项目、对国内访问速度有要求，直接看 CN2 GIA-E，$49.99/季（$169.99/年）的 1GB 套餐是公认的均衡选择。预算充足且对延迟敏感，再考虑香港、东京、新加坡专属线路。

## 四、注册账号：先把账户建好

选好套餐之后，建议先把账号注册好，结账时更顺畅。

1. 打开搬瓦工官网，点右上角 **Register**。
2. 填写邮箱、密码、个人信息。邮箱要写真实可用的，订单确认、续费提醒、退款通知都发到这里。
3. 完成注册后，系统会发一封验证邮件，点链接激活账号。

注册环节没什么坑，注意别用临时邮箱，后续找回密码、收续费提醒都靠这个邮箱。

## 五、下单付款：一步步走完

### 1. 选套餐和计费周期

在套餐页面点 Order Now 后，会让你选计费周期。KVM 普通线路最低年付起，CN2 GIA-E 支持季付起步，香港/东京/新加坡/大阪支持月付和年付。年付通常比月付折算下来便宜不少，但首次购买建议先季付或半年付，跑顺了再续年付。

### 2. 选机房

部分套餐下单时就要选机房，部分套餐是下单后在 KiwiVM 面板里迁。CN2 GIA-E 套餐默认进 DC6 或 DC9，进面板后可以再迁到其他 CN2 GIA 机房。

### 3. 填优惠码

结账页有一个 **Promotional Code** 输入框，填入 `BWHCGLUKKB`，点 Validate Code，价格会按约 6.77% 折扣重新计算。这个码是循环折扣，新购和续费都能用，是目前社区里流传最久、最稳定的搬瓦工优惠码。

> 注意：优惠码折扣力度可能随官方政策调整，下单前在结账页确认实际折扣金额。如果某个套餐显示折扣不生效，可能是该套餐当前不参与活动。

### 4. 选付款方式

搬瓦工支持以下付款方式：

- **支付宝（Alipay）**：国内用户最常用，扫码付款，到账快。
- **PayPal**：国际通用，支持信用卡。
- **信用卡**：Visa/MasterCard 直付。
- **银联（UnionPay）**：部分国内银行卡可用。

选 Alipay 后点 Complete Order，会跳到支付宝扫码页，扫码支付即可。支付成功后订单状态会自动变成 Active，VPS 几秒内开通。

### 5. 查收开通邮件

开通后邮箱会收到一封包含 IP 地址、root 密码、SSH 端口、KiwiVM 面板地址的邮件。这封邮件很重要，建议保存。

## 六、买完之后：KiwiVM 面板和 SSH 登录

### 进入 KiwiVM 面板

登录搬瓦工 Client Area，进 Services → My Services，找到刚买的 VPS，点 **KiwiVM Control Panel**。面板里能看到流量使用、停机记录、快照、迁移、重装系统等所有管理功能。

### 重置 root 密码

首次登录建议先在 KiwiVM 里重置一次 root 密码：Root Password Modification → 生成新密码 → 邮件查收。

### SSH 登录

用 Xshell、Termius、PuTTY、系统自带终端都行：

- Host：VPS 的 IP
- Port：邮件里给的 SSH 端口（不是默认 22）
- 用户名：root
- 密码：刚才重置的那个

连上之后就是一台完整的 Linux 机器，接下来装什么、跑什么，看你自己。

### 机房迁移

CN2 GIA-E 套餐用户可以在 KiwiVM 的 Migrate 功能里切换机房。迁移会重启 VPS、IP 会变，但数据不丢。建议先在低峰期迁，迁完用 Looking Glass 测一下延迟再决定要不要保留。

## 七、几个新手常问的问题

**Q：搬瓦工能退款吗？**
可以。新账户 30 天内、VPS 总数少于 3 个、累计支付金额少于 $100、累计支付次数少于 10 次、IP 未被封，满足这些条件基本能全额退款。退款会注销账号下所有 VPS，不是只退一台。

**Q：流量用超了会怎样？**
搬瓦工流量是月配额，超了会停机或限速，不会自动扣费。可以在 KiwiVM 里看流量使用进度，快超之前自己控制。

**Q：能换 IP 吗？**
普通套餐不能免费换 IP。CN2 GIA-E 套餐通过机房迁移可以换 IP，每次迁移 IP 都会变。

**Q：续费价格会涨吗？**
搬瓦工是循环计费，续费价格和首购一致，优惠码续费也能用。但官方保留调整价格的权利，遇到大规模调价会提前通知。

**Q：KVM 和 CN2 GIA-E 到底差在哪？**
两者都是 KVM 虚拟化，差别在线路。KVM 普通套餐走普通国际线路，国内访问延迟高、晚高峰可能绕路；CN2 GIA-E 走电信 CN2 GIA-E 优化线路，国内访问稳定、延迟低，但价格贵一档。选哪个看你对国内访问速度的要求。
